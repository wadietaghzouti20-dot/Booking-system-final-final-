# The Internet — interactive presentation

A lightweight, self-contained, 16-slide presentation about how to use the internet.

## Present
- Open `index.html` in a modern browser.
- Use **← / →** or **Space** to move between slides.
- Press **N** for speaker notes, **O** for slide overview, and **F** for fullscreen.
- On a touchscreen, swipe left or right.
- Use **PDF** to print or save a PDF copy.

## Publish with GitHub Pages
1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment → Source**, choose **GitHub Actions**.
3. The included workflow deploys the site after each push to `main`.

No external JavaScript libraries, fonts, or image services are required. The deck is designed to work offline once the HTML file is available.
